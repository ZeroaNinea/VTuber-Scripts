# VTuber-Scripts
This repository contains automatic scripts for opening and clothing my VTuber tools.

Place the scripts in the `~/bin` directory of your silly Linux device!
<br />
\>:3

## Launch the Scripts

Make each of the scripts executable:

```bash
chmod +x ~/bin/<SCRIPT_NAME>
```

Launch a script

```bash
~/bin/<SCRIPT_NAME>
```

For example:

```bash
~/bin/vtuber-start
```
